# EVE-O Preview for macOS v0.1.0

First public macOS preview build of the project.

What is included:

- running EVE client discovery
- live preview overlays
- click-to-focus client switching
- saved settings
- persistent thumbnail positions
- packaged `.app` and `.dmg`

Important notes:

- this is an early macOS port, not full feature parity with the Windows version
- macOS may ask for Accessibility, Automation, and Screen Recording permissions
- Apple Silicon build is included by default

Suggested short GitHub release description:

`Early macOS preview release of EVE-O Preview with live thumbnails, client switching, saved settings, and packaged .app/.dmg output.`
